# Glossary

Table 76. Glossary

| Term | Meaning in this document |
|---|---|
| Account group | A node in the chart tree. It has a category, a prefix for account codes and may have a parent group. |
| Advance | Money received from a customer or paid to a vendor that is not set against an invoice. Held on a separate party account. |
| Allocation | Setting part of a receipt or payment against an invoice, which reduces the invoice's outstanding amount. |
| Approved | A trade document that has been approved and so has moved stock and posted to the ledger. Also a voucher that has been posted. |
| Box | A numbered field of the UAE VAT return (form VAT 201). |
| Category | ASSET, LIABILITY, EQUITY, INCOME or EXPENSE: decides which side of the account is its natural balance. |
| Configuration key | The name by which posting code asks for an account or group, for example vat-sales. |
| Cost of goods | The cost of the stock that left on a sale, at the average cost at that moment. |
| Dubai day | A calendar day in UTC+4, from 00:00:00.000 to 23:59:59.999. |
| FEFO | First expiry, first out: batches with the earliest expiry are used first. |
| Fiscal year | A period with a code, a start and an end date and a status (open or closed). A closed year accepts no postings. |
| Group role | cash, bank, receivable, payable, creditCard or other: what an account group holds, worked out from the posting map. |
| Implicit opening | Stock that existed before the first recorded movement of an item. |
| Live entry or movement | One that has not been reversed and is not itself a reversal. |
| Natural balance | Debit - credit for assets and expenses; credit - debit for liabilities, equity and income. |
| Net (debit - credit) | The signed form used by reports that add debits and credits: positive is debit. |
| Opening Balance Equity | The equity account against which all opening balances are posted. |
| Outstanding amount | Total of an invoice less what has been set against it. |
| Posting map | The company's choice of account or group for each configuration key. |
| Posting switch | The company setting that lets trade documents post to the ledger. |
| Reverse charge | A VAT mechanism where the buyer accounts for the VAT; reported in boxes 3 and 10. |
| Reversed | An entry that has been cancelled by a mirror entry; ignored by reports. |
| Round-off | A small difference between a document's computed total and its entered total, kept as an explicit amount. |
| Tax code | A named tax treatment with a kind, a rate and an optional rate history. |
| Weighted-average cost | Total cost on hand divided by quantity on hand, recalculated on each purchase; a sale does not change it. |
