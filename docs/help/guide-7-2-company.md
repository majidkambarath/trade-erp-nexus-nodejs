# Company

The name, address, contact details and logo of the company.

| Field | Rule |
|---|---|
| Company name | Required, up to 100 characters. |
| Email address | Optional, checked as an email. The server accepts only 2 or 3 letters after the last dot, so an address ending in a longer ending, such as.info, passes the screen and then fails on save. |
| Address line 1, city, state or emirate | Required. Address line 1 up to 100 characters, city and state up to 50. For the UAE the emirate offers the seven emirates. |
| Address line 2, postal code, phone, website | Optional, with length limits (100, 20, 20, 100). |
| Country | A list of 16 countries; default United Arab Emirates. |
| Logo | PNG or JPG, up to 5 MB, resized to fit 800 by 800 pixels, stored with an image-hosting service. |

One Save changes bar saves the Company and Invoice bank details tabs together. Discard returns to the last saved values. The page shows when there are unsaved changes.
