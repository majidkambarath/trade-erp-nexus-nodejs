# Navigation and the shell

The screens around the modules are the same everywhere.

Left rail. A narrow rail of labelled modules. A click opens the module's first tab. Settings sits at the bottom. A small dot marks a module that holds a Soon tab (Reports, because of e-Invoicing).

Header tabs. A row of tabs for the module in use, shown for modules with two or more tabs.

Search pages (Ctrl+K, or Cmd+K on a Mac). Opens a command palette that finds any page by name, module or keyword (for example pay vouch finds Payments). It searches pages, not records.

Top bar. The brand name (NH FOODS for the first client), the search button, and an avatar menu with Settings, a Dark mode switch and Log out. Signing out clears the browser's tokens and does not call the server.

Small screens. Below 640 pixels the rail becomes a drawer listing every module and page.

| Note. The menu role lists are carried in the configuration but not applied: every signed-in user sees every tab (section 3). The routes themselves have no guard in the browser; protection is on the server. |
