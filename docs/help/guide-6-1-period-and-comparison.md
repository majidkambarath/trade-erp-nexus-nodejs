# Period and comparison

Every figure on every tab is for one period, compared with the period before it.

One period selector (This week, This month, This quarter; default This month) sits on the Dashboard tab. The other tabs follow it. The server also accepts a named month or a start and end date, but the screen has no control for them.

A week runs from Monday to today, a month from the 1st to today, a quarter from its first day to today. Each is compared with the same stretch before it (the month so far against the previous month up to the same day number). Reorder and expiry lists are always today's position.
