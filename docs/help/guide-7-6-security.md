# Security

Password and sign-in protection.

Change password: the current password, a new password of at least 6 characters that differs from the current one, and a confirmation. A strength bar is advice only and is not enforced.

Five wrong sign-in attempts lock the account for 2 hours, even if the right password is then entered.

Existing sessions are not ended when the password changes.

There is no self-service password reset and no sign-up. The sign-in page says to ask the administrator.

Signing out clears the tokens from the browser. The server is not called.
