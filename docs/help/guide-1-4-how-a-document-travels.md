# How a document travels

A business document passes through the same layers every time. The screen collects what the user types and shows warnings. The server checks, prices, moves stock and cost, and writes the ledger. Reports only read.

| Screen | → | Server checks | → | Stock and cost | → | Ledger | → | Reports |
|---|---|---|---|---|---|---|---|---|
