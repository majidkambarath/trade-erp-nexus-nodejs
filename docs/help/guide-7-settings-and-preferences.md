# Settings and preferences

Settings holds the details of the company, the business rules the server applies, the bank details printed on invoices, each user's display preferences and the password. This section says what each control does and where its value is saved, because the answer differs: some values belong to the company, some to the signed-in user, and some to the browser only.

Settings has five tabs, kept in the address (for example /settings?tab=rules). Tax codes, document numbering, fiscal years and posting accounts are not here: they are in Accounts, Setup.
