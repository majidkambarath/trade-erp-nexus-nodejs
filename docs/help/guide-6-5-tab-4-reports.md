# Tab 4: Reports

Profit, VAT, vouchers posted and ageing at a glance.

| Widget | What it shows |
|---|---|
| Gross profit and Net profit | Both from the profit and loss for the period, each linking to the statement. |
| VAT payable or refundable | The VAT return net for the quarter so far. |
| Value growth | Gross profit by month for 8 months. |
| Voucher tiles | Receipt, Payment, Journal, Contra and Expense: the amount posted in the period, or None posted. |
| Receivables and payables ageing | The same five buckets as the Ageing report, as at the period end. |
| VAT snapshot | Output VAT, input VAT and the net for the quarter so far, as a donut. |

### When there is nothing to show, or a part fails

A widget with no data shows a grey box with a specific message, for example "No sales this month". A figure that cannot be computed shows a dash.

A part that fails to load shows "This could not be loaded" in the card, or an error note with a Try again button for the whole tab.

The refresh button reloads every tab that has been opened. A late answer never overwrites a newer one.

The dashboard has no role restriction: any signed-in user sees all four tabs.
