# Preferences

How dates, times and colours appear for the person using this browser.

| Preference | Options | Default |
|---|---|---|
| Theme | Light, Dark, Match device | Light |
| Date format | DD/MM/YYYY, MM/DD/YYYY, YYYY-MM-DD, DD-MM-YYYY, DD MMM YYYY | DD/MM/YYYY |
| Time format | 24-hour, 12-hour | 24-hour |

A change applies at once and is remembered in this browser. It is not saved on the server.

Every date shown goes through one formatter that follows the date and time preference and shows Dubai time. The time zone cannot be changed by the user.

Date fields type and display in the chosen format and always send the same standard date to the server.

Two items on this tab are marked Coming soon: Language (Arabic with a right-to-left layout alongside English) and Notifications (alerts for approvals, low stock, expiring batches and overdue invoices).
