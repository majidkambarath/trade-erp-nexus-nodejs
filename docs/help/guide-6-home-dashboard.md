# Home dashboard

The dashboard is the owner's one-screen view of the business: sales, margin, collections, stock, VAT and what needs attention. This section lists what each tab shows and where each figure comes from, so you know which numbers to trust and what they leave out.

| Rule. Every figure on the dashboard is calculated by the server from the ledger and from approved documents. Nothing is typed in, sampled or invented. A widget with nothing to show says so inside its own card. There are no targets, branches or fleet figures. |
|---|

Status. The dashboard code carries no mock, sample or random data in any of its four tabs, and its server calculation and tests are in place.
